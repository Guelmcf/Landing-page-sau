# Landing-page-sau

#objective:
Create a interactive landing page for Sau an company who serves meals for other comanies, the main goal of this site is to be an way of potential clients to find an ask for a initial budget.

#stack:
- React (for creating and managing grapic components)
- typescript (the base language used in React)
- vite (the framework used to Run React)
- css (styling)
